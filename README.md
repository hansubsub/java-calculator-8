# java-calculator-precourse

## 구현할 기능 목록✔️

### 기능

---

- [ ]  입력을 받는다
- [ ]  커스텀 구분자를 확인한다.
   - [ ]  “//”와 “\n”사이의 문자가 커스텀 구분자
   - [ ]  커스텀 구분자의 길이는 5자로 제한
   - [ ]  커스텀 구분자 개수는 1개로 제한
   - [ ]  커스텀 구분자로 숫자는 안된다.
- [ ]  구분자를 기준으로 분리한다.
- [ ]  분리된 각 숫자를 합한다.
- [ ]  결과를 출력한다.

### 예외

---

- [ ]  잘못된 값이 입력되면  IllegalArgumentException 발생시킨 후 애플리케이션은 종료
    - [ ]  입력값에 음수가 포함될 경우
    - [ ]  구분자 사이 값이 숫자가 아닌 경우
    - [ ]  커스텀 구분자 기본 구분자 외에 문자가 있는 경우
